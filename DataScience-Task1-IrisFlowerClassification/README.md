# Iris Flower Classification

## Project Overview
This project aims to classify Iris flowers into three species (Setosa, Versicolor, and Virginica) using Machine Learning algorithms.

## Dataset
The Iris dataset is provided by Scikit-learn and contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Logistic Regression
- Random Forest

## Results

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 100% |
| Random Forest | 100% |

## Conclusion
Both models achieved 100% accuracy. Logistic Regression was selected as the final model because it is simpler, faster, and easier to interpret.
